### 🚀 Featured Projects

#### 🔎 [ResearchMind — Multi-Agent AI Research Assistant](https://github.com/Sohel123-png/Multi-agent-research-system)
`Python` `Mistral AI` `FastAPI` `SSE` `JavaScript` &nbsp;•&nbsp; [🔗 Live Demo](https://multi-agent-research-system-1-zbio.onrender.com/)

A modular **four-stage agentic workflow** (Search → Read → Write → Critique) powered by Mistral AI that automates end-to-end research generation.
- Integrated Tavily Search API + BeautifulSoup for intelligent web-scraping and information extraction
- Built a FastAPI backend using **Server-Sent Events (SSE)** to stream real-time agent execution status to the frontend

#### 💳 [Loan Default Risk Prediction Platform](https://github.com/Sohel123-png/Loan_Default-Prediction)
`Python` `Pandas` `Scikit-learn` `FastAPI` &nbsp;•&nbsp; [🔗 Live Demo](https://loan-default-prediction-6sqs.onrender.com)

An end-to-end predictive classification system benchmarking **XGBoost and ensemble methods** for default-risk identification.
- Built a robust preprocessing pipeline: median imputation, Z-score outlier detection, One-Hot encoding
- Tuned models via **RandomizedSearchCV**, improving F1-score and generalizability
- Deployed as a REST API with FastAPI + Joblib, with interactive Swagger docs

#### 🔬 [Cell Analyzer — Microscopy Image Analysis Platform](https://github.com/Sohel123-png/cell_analyzer)
`Python` `Flask` `OpenCV` `scikit-image` `SciPy` &nbsp;•&nbsp; [🔗 Live Demo](https://cell-analyzer.onrender.com)

An end-to-end computer vision application for microscopy image analysis — cell/nuclei segmentation, quantitative feature extraction, and automated quality control, built on an **OpenCV**-based classical CV pipeline.
- Full pipeline: thresholding → morphological cleanup → distance transform → **watershed segmentation**
- Flask REST API + browser dashboard with per-cell CSV export and benchmarking against public datasets

#### 🕵️ [Credit Card Fraud Detection Framework](https://github.com/Sohel123-png/Credit-Card-Fraud-Detection)
`Python` `Pandas` `NumPy` `Scikit-learn` `SMOTE`

A fraud detection framework built to identify anomalous transactions in **highly imbalanced** financial data.
- Applied **SMOTE** to correct class imbalance, boosting minority-class recall by 15%
- Validated with Precision-Recall curves and ROC-AUC analysis for reliable fraud detection
